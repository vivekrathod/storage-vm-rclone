# Privacy policy for storage-vm rclone

storage-vm rclone is a personal Google OAuth client used only by its owner, Vivek Rathod, to run rclone backups from his own home-lab storage VM to his own Google Drive.

It requests only the Google Drive drive.file scope, so it can access only files that rclone itself creates in the owner's Drive. It does not read any other Drive files, email, contacts or profile data.

No data is collected, sold or shared with anyone. The OAuth token is stored only on the owner's own machine. Access can be revoked at any time at https://myaccount.google.com/permissions.

Contact: rathod.vivek@gmail.com
